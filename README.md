Hi, I'm Gildor. I build small, dependency-free TypeScript libraries, mostly
around Cardano tooling and Czech fintech and data utilities.

**Cardano**

- [cardano-bech32-utils](https://github.com/gildor853/cardano-bech32-utils): encode, decode and inspect Cardano bech32 addresses (CIP-19, CIP-5).
- [cardano-slot-time](https://github.com/gildor853/cardano-slot-time): convert between slots, POSIX time and epochs on mainnet, preprod and preview.
- [cardano-asset-name](https://github.com/gildor853/cardano-asset-name): native asset IDs, CIP-14 fingerprints and CIP-67/68 labels.

**Czech**

- [cnb-rates](https://github.com/gildor853/cnb-rates): Czech National Bank daily exchange rates, with conversion through CZK.
- [cz-validators](https://github.com/gildor853/cz-validators): validators for IČO, DIČ, rodné číslo, bank account numbers, IBAN and PSČ.
- [cz-qr-platba](https://github.com/gildor853/cz-qr-platba): generate and parse Czech QR payment strings (SPAYD).

**General**

- [exact-units](https://github.com/gildor853/exact-units): unit conversion with exact fractions instead of floating point, typed by dimension.
- [tabular-convert](https://github.com/gildor853/tabular-convert): convert tables between CSV, JSON, Excel, SQL, Markdown and HTML, from code or the command line.
- [ua-lens](https://github.com/gildor853/ua-lens): parse User-Agent strings and Client Hints, and recognise crawlers and AI bots from their documented tokens.
- [file-sentinel](https://github.com/gildor853/file-sentinel): static heuristic scan of untrusted files for active content, macros and type spoofing.

Mostly TypeScript. I like small APIs, real test vectors and boring, predictable code.
